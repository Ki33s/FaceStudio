VIDEOSTUDIO — Cutter и FaceStudio в одном окне

Запуск установленной версии: C:\AI\FaceStudio\VideoStudio.exe.
Все операции выполняются локально. Приложение использует уже установленный
движок FaceStudio, его модели, Python и FFmpeg.

1. Перетащите видео или нажмите «Открыть видео».
2. Под предпросмотром находится постоянная панель «ОБРЕЗКА ВИДЕО». Выберите фрагмент зелёными границами либо введите начало и конец. Нажмите большую зелёную кнопку «Сохранить фрагмент», чтобы вырезать нужный момент в отдельный MP4.
3. Чтобы оставить исходные лица в отдельных моментах, выделите каждый
   момент на шкале и нажмите «Оставить лица в выделенном моменте».
   Оранжевые отметки остаются в видео, замена всех лиц на них пропускается.
   Можно добавить несколько отметок или убрать выбранную из списка.
   Двойной щелчок по отметке выделяет её на шкале.
   После разметки выберите границы фрагмента для обрезки.
   При обрезке отметки автоматически сдвигаются, лишние отбрасываются.
   Они сохраняются при повторном открытии файла и вместе с проектом.
   Обработка и исправления проекта сохраняют исходные кадры на отметках.
   Отметки для новой замены редактируются в режиме «Исходник».
4. «Сохранить фрагмент» сохраняет MP4 в выбранную вами папку.
5. «Для замены лиц →» делает выбранный фрагмент новым исходником.
   После этого нажмите «Заменить лица» и назначьте фотографии людям.
   Ограничения в две минуты нет: можно обработать видео целиком.
6. После обработки смотрите результат, сохраняйте его или исправляйте
   по описанию. Проверка качества и отмена сохранены из FaceStudio.

Можно обрезать и результат замены лиц: переключитесь на «Результат»,
выберите границы и нажмите «Сохранить фрагмент».
Шкала и надпись «Обрезка: исходник/результат» всегда относятся к видео
в текущем предпросмотре. При переключении видео границы сбрасываются.

Точно: MP4 с H.264/AAC, высокое качество, обрезка по выбранному времени.
Быстро: копирование дорожек без перекодирования; начало может смещаться
к ключевому кадру, некоторые форматы не подходят для MP4.
Фрагмент для замены лиц всегда сохраняется в точном режиме.
При наличии отметок без замены лиц точный режим применяется и к сохранению.
Отметки хранятся в data\edit-marks; для обмена проектом они входят в project.json.
Сохранение в MP4 перекодирует видео: отсутствие замены означает исходное
содержимое кадра, а не побитовое совпадение файла.

Исходные файлы не изменяются. Фрагменты для дальнейшей замены сохраняются
в data\clips, поскольку проекты FaceStudio ссылаются на них.

I — отметить начало; O — конец; пробел — воспроизведение/пауза.
Кнопки «− кадр» и «+ кадр» помогают точно выбрать момент.

FaceStudio.exe и Cutter.exe остаются доступными отдельно.
Исходники объединённого интерфейса: source\VideoStudio.

ОБРАБОТКА ДЛИННЫХ ВИДЕО

Поиск людей и замена лиц выполняются последовательно частями до 60 секунд.
После готовой части программа сохраняет её и автоматически продолжает.
Фотографии назначаются людям один раз для всего видео. Между частями
модели выгружаются, сохранённые данные ограничивают расход памяти.
Процессы работают с пониженным приоритетом; нагрузка на GPU при обработке
остаётся, поэтому это не режим отсутствия нагрузки.

При остановке или закрытии приложения готовые части остаются. При новом
запуске открывается незавершённый проект с кнопкой «Продолжить обработку».
Эта кнопка нужна только после остановки; во время работы нажатий не требуется.
Незавершённая текущая часть будет обработана снова, готовые пропускаются.
Если остановлен поиск людей, нажмите «Заменить лица» для его продолжения.

Сохранённые части: data\projects\<проект>\revision-<номер>\part-0001\render.mp4
Журнал очереди: chunks.json в той же папке revision.
В конце части объединяются в общий MP4 без повторного кодирования видео,
со звуком исходника. Готовые минутные части остаются на диске.

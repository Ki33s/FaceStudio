# FaceStudio 2.10 — исходники Windows-приложения

Локальная замена лиц, назначение фотографий персонажам, объединение повторных
карточек, исправление по описанию и сохранение результата. VideoStudio также
предоставляет обрезку видео и отметки участков без замены.

В репозитории находятся собственные Python-модули, исходники интерфейса и
скрипты сборки. Здесь нет пользовательских фото, видео, проектов, журналов,
готовых EXE, моделей и среды runtime. Описание ниже относится к полной
установленной версии; после клонирования runtime нужно добавить отдельно.

## Сборка и запуск

Нужны Windows x64 и .NET Framework 4.8. Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\source\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\source\VideoStudio\build.ps1
```

Для работы скопируйте целиком каталог `runtime` из существующей установки
FaceStudio в корень клона. Сохраняйте его структуру:

```text
runtime/
  python/python.exe
  directml/          # пакеты Python и ONNX Runtime DirectML
  facefusion/       # FaceFusion, его модели и лицензии
  bin/              # FFmpeg и FFprobe
  licenses/
```

Не добавляйте runtime в Git: он занимает несколько гигабайт и содержит
зависимости и модели с отдельными лицензиями. Автоматического установщика
runtime в этом репозитории нет. Проверенные версии перечислены в
`docs/runtime-versions.json`. Ollama устанавливается отдельно, модель
загружается отдельно. Обработка лиц использует HyperSwap 1a 256 и XSeg 1.

Затем запустите `FaceStudio.exe` или `VideoStudio.exe`. Каталог `data` создаётся
локально; он исключён из Git. Программа не отправляет ваши материалы на GitHub.

# FaceStudio 2.9 — локальная замена лица

План обработки сохраняет найденные лица и пропускает дорогую замену на кадрах
без подходящего выбранного лица. Видео остаётся целым, со звуком и прежней
длительностью. Слабые и сильно смазанные обнаружения не требуют повторного
нейросетевого поиска. Назначения фотографий и группы сохраняются.

Хорошие профили допускаются без проверки пропорций анфаса. Краткий сбой
уверенности между двумя подтверждёнными появлениями компенсируется по уже
измеренным точкам. Сглаживание не смешивает заметно разные повороты головы;
пустые кадры не заполняются выдуманными лицами. Неопределённый дубль того же
лица не накладывает исходник поверх подтверждённой замены.

Маска перекрытий теперь использует DirectML на совместимой видеокарте,
с запасным расчётом на CPU. Качество замены 512×512 сохранено. Обычная замена
не запускает автоматический повторный рендер почти всей минуты. Исправление
по описанию доступно отдельно после просмотра.

Для применения обновления перезапустите приложение и запустите замену заново.
Уже сохранённые результаты не меняются. Сильное размытие, перекрытия и отсутствие
измерения всё ещё могут приводить к пропускам. Подробнее: [план обработки 2.9](docs/selection-2.9.md).

# FaceStudio — локальная замена лица

Версия 2.6 сохраняет назначения фото и группы после каждого изменения в окне
выбора. При повторном открытии того же видео они восстанавливаются из
`data/scans/<поиск>/assignments.json`. Нажатие «Начать» дополнительно сохраняет
выбор до проверки и создания проекта, поэтому ошибка подготовки не требует
вводить фотографии повторно.

Поиск сохраняет дорожку между соседними кадрами по проверенному оптическому
движению внутри лица. Изменение ракурса не требует совпадения только с одним
усреднённым портретом: на человека сохраняется небольшая галерея ракурсов.
Пересечение лиц, смена сцены или сильное противоречие распознаванию не дают
перенести назначение на другую дорожку. Короткие пропуски подтверждаются только
реальными обнаружениями; пустые кадры не получают выдуманного лица.

Повторные появления могут объединяться автоматически; группу можно разделить.
Сохранённые одинаковые назначения объединяются по выбранной пользователем
фотографии, без повторного поиска. Исходные номера появлений и индивидуальные
назначения сохраняются, одновременно видимые лица обрабатываются раздельно.
Автоматическое объединение не гарантирует, что все дубликаты будут найдены.

Исправлена несовместимость поиска с заново закодированной временной шкалой.
Перенос старой разметки допускается только при совпадении исходника, размеров,
частоты и числа кадров и дополнительной проверке содержимого в нескольких
моментах. Новая подготовка сохраняется отдельным файлом и не перезаписывает
видео, на которое уже ссылается существующий поиск.

Версия 2.5 отдаёт приоритет качеству. Замена выполняется с Pixel Boost 512×512
(четыре прохода существующей модели на лицо), а XSeg заново измеряет перекрытия
для каждого заменяемого лица на каждом кадре. Маска больше не пропускается у
уверенно найденных лиц и не переносится с предыдущего кадра. Это помогает
сохранять руки и предметы перед лицом; сложные перекрытия всё ещё могут давать
ошибки. Разрешение самого видео не увеличивается.

Кодирование результата использует высокое качество и медленный пресет.
При подготовке видео с переменной частотой кадров и вставке исправленного
участка также уменьшены потери кодирования. Работа занимает больше времени,
файлы могут стать больше. Старые результаты автоматически не переписываются.
При продолжении незавершённой обработки старые части пересчитываются в новом
режиме; уже готовые части того же режима используются повторно. Новые модели
скачивать не требуется. Маска работает на CPU, замена — через DirectML.

Режим включён по умолчанию и подписан в интерфейсе. 512×512 — размер внутренней
обработки лица, а не гарантия исходной детализации. Размытые, закрытые и выходящие
за кадр лица могут оставаться с дефектами; отчёт о пропусках сохраняется.

Обновление 2.4: крупное и частично обрезанное лицо удерживается по подтверждённой хронологии, признакам текущего кадра и соседним кадрам. При слабом распознавании используется дополнительный масштаб детектора; разметка глаз вне кадра не подменяется выдуманными точками внутри изображения. Хронология сохраняется и повторно используется при исправлениях. Маска перекрытий сохраняет руку и предметы перед лицом. Участки без замены перечисляются в отчёте: проверка небольшой выборки кадров не означает, что заменён весь ролик.

В окне назначения отметьте карточки одного человека и нажмите **«Это один человек»**. Получится одна карточка с несколькими портретами, фото назначается всей группе. **«Фото выбранным»** применяет одну фотографию сразу к отмеченным карточкам. **«Разделить группу»** возвращает отдельные карточки. При конфликте уже назначенных фото программа предлагает выбрать одно; отмена сохраняет прежние назначения. Группы сохраняются вместе с проектом. Если появления группы не пересекаются в кадре, они обрабатываются как одна хронология; одновременно видимые лица сохраняют отдельные дорожки.

Обновление 2.3.1: отслеживание между соседними кадрами удерживает назначенное лицо при изменении мимики и ракурса. При смене сцены пространственная привязка сбрасывается. В старых проектах короткие пропуски восстанавливаются по соседним подтверждённым кадрам и сохраняются в кэше; назначения фотографий не меняются. При продолжении старой обработки части с прежним алгоритмом пересчитываются. Кнопка «Открыть папку» сделана заметнее.

Дважды нажмите **FaceStudio.exe**. Откроется отдельное приложение Windows со встроенным видеоплеером.
Вкладка браузера и локальный веб-сервер для нового интерфейса не нужны. **Запустить.cmd** также открывает это окно.
Если Ollama выключена, программа найдёт установленную Ollama, запустит сервер в фоне и дождётся ответа.
Модель qwen3.5:9b используется автоматически, если установлена; иначе выбирается первая доступная модель.
Фото, видео и команды обрабатываются на вашем компьютере. Интернет для работы с уже установленными моделями не нужен.

1. Перетащите видео из Проводника в окно или нажмите **«Открыть видео»**. Появятся название, длительность и предпросмотр.
   Нажмите **«Заменить лица»**. Программа найдёт людей по всему ролику, включая появляющихся позже. Загрузка файла сама замену не запускает.
2. В открывшемся окне рядом с портретом нужного человека выберите фото для замены. При желании добавьте до двух фото того же лица для глаз и ракурса.
   Можно назначить разным людям разные фотографии или нажать **«Одно фото всем»**. Люди без назначенного фото сохраняются без замены.
3. Нажмите **«Начать»**. Замена, техническая проверка и автоматическое исправление нестабильных участков запускаются без текста.
4. По готовности нового видео прозвучит сигнал. Посмотрите результат. Если нужна дополнительная коррекция, опишите проблему в поле **«Что исправить?»**
   и нажмите **«Исправить по описанию»** или Ctrl+Enter. Кнопка **«Проверить результат»** повторяет техническую проверку без изменения видео и без загрузки модели Ollama.

Примеров команд в интерфейсе нет; поле команды изначально пустое и доступно после появления результата.
Текст для первой замены не нужен. Ручных настроек коррекции, цветокоррекции и обрезки нет.
Под видео есть полоса перемотки для просмотра результата. Длительность сохраняется. При исправлении используется исходное видео,
а указанный участок вставляется в предыдущий результат. Звук предыдущего результата копируется без перекодирования.
Видео при сборке перекодируется, поэтому байты вне исправленного участка не будут идентичными исходному файлу.

## Проверка и автоматическое исправление

Точки лица сглаживаются с учётом движения между кадрами. Подозрительные участки проходят один дополнительный
проход с усиленным сглаживанием. Новый вариант принимается, если 95-й процентиль нестабильности точек лица
на этом участке не стал хуже; при ухудшении сохраняется первый вариант. Проверяются декодирование, длительность и наличие исходного звука.
Долгая оценка кадров в Ollama отключена. После замены и исправления остаются технические проверки.
Ollama используется только для разбора текстовой команды. Технические проверки не гарантируют отсутствие видимых дефектов; просмотрите результат.
Кадры без найденного лица сохраняются без замены. Вспомогательное фото используется только при достаточном
сходстве с основным лицом; на групповом фото выбирается похожее лицо автоматически.
В основном фото лучше использовать одного человека: если лиц несколько, программа берёт самое крупное.
Исходное фото проверяется с более строгими порогами, чем видео: ноги, рисунки на одежде и другие слабые
ложные срабатывания отбрасываются. Подготовленное лицо проверяется повторно перед заменой.
На нескольких кадрах отдельно проверяются изменение пикселей лица и увеличение сходства с исходной фотографией.
Если изменения лица не обнаружены, программа сообщает об ошибке, а не принимает неизменённое видео как готовое.
Оценка сходства является дополнительной проверкой и не гарантирует точность лица на каждом кадре.
Проверка изменений выполняется отдельно для каждого назначенного человека. При исправлении конкретного человека
его номер можно указать в тексте; без номера исправляются все назначенные лица на указанном участке.
Фото и номера сохраняются вместе с проектом. При исправлении одного человека остальные замены берутся из предыдущего результата.
При неуверенном сопоставлении кадр пропускается. Маленькие, закрытые или сильно повёрнутые лица могут быть пропущены,
а при сильном изменении внешности один человек иногда может появиться в нескольких карточках. Проверьте портреты перед назначением.

Ограничение длительности видео в две минуты снято. Программа работает с несколькими персонажами на Windows с DirectML.
Поиск людей и обработка выполняются последовательно частями до 60 секунд. Длинные видео требуют больше времени и свободного места на диске.
В версии 2.3 исправлен расчёт времени для записей Bandicam и других видео с переменной частотой кадров.
Перед новым поиском такое видео автоматически приводится к постоянной частоте в рабочей копии; исходный файл сохраняется.
Все люди используют одну общую подготовку движения: кадры читаются один раз для выбранных людей, карта сохраняется в проекте.
При исправлении участка используется сохранённая карта. Повторный поиск людей не требуется.
В VideoStudio незавершённую работу можно возобновить кнопкой «Продолжить обработку»; уже готовые части используются повторно.
На этом компьютере используется Radeon RX 6600. FaceFusion и Ollama запускаются последовательно,
чтобы освобождать видеопамять между задачами. Разбор команды иногда занимает десятки секунд.

Все результаты, отчёты и оригиналы сохраняются в **data/projects**. «Открыть последний результат» восстанавливает
последнюю законченную работу после перезапуска. При запуске последний результат также открывается автоматически.
Кнопка «Сохранить видео» копирует результат в выбранное вами место; «Открыть папку» показывает его в Проводнике.
Кнопка «Заменить лица» открывает назначения для выбранного видео и после «Начать» создаёт новый проект.
Поиск людей сохраняется в **data/scans**; после запуска замены он копируется в проект, чтобы папку можно было переносить.
При проверке или исправлении по описанию используются файлы проекта с последним результатом.
Кнопки **«Исходник»** и **«Результат»** переключают предпросмотр. Пробел включает воспроизведение или паузу.
Поддерживаются MP4, MOV, MKV, AVI, M4V, MPEG, MXF, WEBM и WMV. Если Windows не открывает кодек, программа
подготавливает совместимую копию для предпросмотра. Для замены всегда используется выбранный оригинал.
Чтобы закрыть приложение, закройте его окно. «Отменить обработку» останавливает текущую задачу, сохраняя предыдущий
законченный результат. При закрытии окна во время обработки программа предложит отменить задачу.
**Остановить.cmd** также закрывает окно. Ollama обычно остаётся доступной; если сервер был запущен внутри отменяемой задачи,
при следующем запуске программа снова проверит и при необходимости включит его.

## Состав

Нативный интерфейс использует Windows Forms и WPF (.NET Framework 4.8). Python, FFmpeg, FaceFusion и модели замены
уже находятся в **runtime**. Установщик на этом компьютере не нужен.
Можно перенести всю папку FaceStudio в другое место на этом компьютере. Для другого компьютера понадобится
Windows, совместимый DirectML и отдельная установка Ollama с моделью. Модель Ollama в эту папку не включена.
Встроенные проверки содержимого FaceFusion сохранены. Созданные видео являются синтетическим монтажом.
Оформление WPF основано на исходниках локального приложения Cutter. Исходники интерфейса, звук и скрипт сборки находятся в **source**.

Лицензии зависимостей находятся в runtime/facefusion/LICENSE.md, runtime/licenses и каталогах пакетов Python.
FaceFusion: https://github.com/facefusion/facefusion ; Ollama: https://github.com/ollama/ollama

Если запуск завершился ошибкой, откройте **desktop-error.log**, если он появился. Ошибки обработки находятся в
**data/projects/<проект>/<версия>/engine.log**. При нехватке видеопамяти закройте другие приложения, использующие GPU.
Лог поиска людей находится в **data/scans/<поиск>/scan.log**.

Прежний веб-интерфейс сохранён в app.py как часть совместимого обработчика. Новый FaceStudio.exe не запускает его сервер.
